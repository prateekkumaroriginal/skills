# Skills

- `html-plans`: Creates self-contained HTML plans with a cool near-black canvas, one blue accent, Archivo titles, Geist text on a 4px type scale, and space instead of section separators.
- `grill-with-ui`: Presents `grill-with-docs` through an interactive answer UI. Requires `grill-with-docs`; invoke explicitly with `$grill-with-ui`.
- `rf-loop`: Creates a PR, addresses worthwhile review findings for up to three rounds, and merges when clear. Invoke explicitly with `$rf-loop`.
- `slime-fill-rule`: Writes and validates importable rule JSON for the Slime form-fill Chrome extension, including custom dropdowns, radios and checkboxes.
- `voice-over` generates natural video narration with local Qwen3-TTS, listener-specific direction, and individually retakable passages.
- `choreography` guides animation and transition choices for motion-graphic videos, including narration cues, chart spotlights, and readable comparison holds.
