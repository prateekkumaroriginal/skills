# Skills

- `html-plans`: Creates Cursor-style plans as browser-viewable HTML documents.
- `grill-with-ui`: Presents `grill-with-docs` through an interactive answer UI. Requires `grill-with-docs`; invoke explicitly with `$grill-with-ui`.
- `full-send`: Creates a PR, addresses worthwhile review findings for up to three rounds, and merges when clear. Invoke explicitly with `$full-send`.
